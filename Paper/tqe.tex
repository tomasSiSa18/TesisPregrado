\subsection{Quantum Information and Computation}

\begin{definition}
    Quantum states \cite{watrous_quantum_channels}: A quantum state of the system X is described by a density matrix $\rho$ whose entries are complex numbers and whose indices (for both its rows and columns) have been place in correspondence with the classical state set $\Sigma$
\end{definition}

\begin{definition}
    Mixed state \cite{zhou2017differential}: A mixed state of a quantum system is an ensemble

    $$\mathbb{E} = \{(p_1,\ket{\psi_1}),...,(p_k,\ket{\psi_k})\}$$

    which in turn can be represented by the density operator

    $$\rho_{\mathbb{E}} = \sum_{i}p_i\ket{\psi_i}\bra{\psi_i}$$

    thus the resulting $\rho_{\mathbb{E}}$ will be the density matrix representation of the ensemble.
\end{definition}

\begin{definition}
    Quantum Channel \cite{watrous_quantum_channels}: A quantum channel describes a linear mapping over density matrices. 
\end{definition}

Quantum channels are important as they are the generalization of an operation over a quantum state and in the case of this project we need to use operations such as the depolarizing channel which is defined thanks to this general definition.

\begin{definition}
    Bloch spehere \cite{watrous_quantum_channels}: The Bloch sphere is a useful geometrical representation for a single qubit. 
\end{definition}

\begin{definition}
  \label{def:trace_distance}
    Trace distance \cite{zhou2017differential}: It is the distance between two density operators and it is defined by:

    $$\tau(\rho, \sigma) = \frac{1}{2}Tr\abs{\rho - \sigma}$$

    where $Tr(x)$ is the trace of the density matrix $x$
\end{definition}

another useful form to define the trace distance in terms of vectors by Nielsen $\&$ Chuang \cite{Nielsen_Chuang_2010} is 

\begin{definition}
  \label{def:trace_distance_vector}
    Trace distance \cite{Nielsen_Chuang_2010}: It is the distance between two qubit vectors $u$ and $v$ defined by:

    $$\tau(u, v) = \frac{1}{2}\norm{u - v}$$
\end{definition}



\begin{definition}
    Quantum measurement \cite{zhou2017differential}: It is the way to extract information from a quantum system. Mathematically, a measurement is modelled as a set of matrices $M = \{K_m\}$ with the condition of 

    $$\sum_m K^{\dagger}_{m}K_{m} = I$$

    with $I$ being the identity of the density operator (i.e for a qubit $I = 2\times2$ identity matrix)

\end{definition}

When talking about quantum differential privacy below it won't really matter what the quantum state collapses into. Given this liberty we can define a POVM (Positive Operator-Valued Measure) which is a simplification over the measurement where we get a set of matrices $M = \{M_m\}$ with $M_m = K^{\dagger}_{m}K_{m}$ $\forall m$ this is possible since we only care about the probabilities and so $p_m = Tr(K_{m} \rho K^{\dagger}_{m}) = Tr(M_m\rho)$

\begin{definition}
    Quantum noise \cite{zhou2017differential}: It is an inherent physical process that occurs on the quantum state that causes it to change in some way.
\end{definition}

For the purposes of this investigation we are interested in three types of noise: General amplitude damping, Phase-amplitude damping and Depolarizing noise. Each one of these types represent a unique physical process which is summarized in greater detail in \cite{song2025hybrid} and \cite{zhou2017differential}. However for this proposal it is only necessary to note that these processes will randomize the quantum state by a certain degree. 

\subsection{Differential Privacy}

\begin{definition}
    ($\epsilon$, $\delta$)-Differential privacy \cite{dwork2014algorithmic}. A randomized algorithm $\mathcal{M}$ will provide ($\epsilon$, $\delta$)-Differential privacy (henceforth ($\epsilon$, $\delta$)-DP) if for any two outputs on two different databases D and D' differing by at most one record, and for all possible outputs $A$:

    $$Pr[\mathcal{M}(D) \in A] \leq e^{\epsilon}Pr[\mathcal{M}(D') \in A] + \delta$$
\end{definition}

\subsection{Quantum Differential Privacy}

\begin{definition}
    (Quantum differential privacy \cite{zhou2017differential}). Let $d \in (0,1]$ and $\epsilon,\delta > 0$ be three constants. A quantum operation $\mathcal{E}$ is $(\epsilon, \delta)$-differentially private if for every POVM $M = {M_m}$, for all outputs $S \subseteq Out(M)$ and for all inputs $\rho, \sigma$ such that $\tau(\rho, \sigma)\leq d$, it holds that:

    $$Pr[\mathcal{E}(\rho)\in_{M}S] \leq e^{\epsilon} Pr[\mathcal{E}(\sigma)\in_{M}S] + \delta$$
\end{definition}

There are many ways to obtain that epsilon in theory however Zhou and Ying proposed the following algorithm to obtain a quantity called proportional distance which can help obtain $\epsilon$.

\begin{definition}
    (Proportional Distance \cite{zhou2017differential}). For two density operators $\rho$ and $\sigma$, their proportional distance is defined as:

    $$PD(\rho, \sigma) = \sup_{\{M_m\}, m} \max\left(\ln\frac{q_m}{p_m}, \ln\frac{p_m}{q_m}\right)$$

    where the supremum is over all POVMs $\{M_m\}$ and all possible outcomes $m$,

    $$p_m \equiv Tr[\rho M_m], \quad q_m \equiv Tr[\sigma M_m]$$

    are the probabilities of obtaining outcome $m$ when the measurement is performed on $\rho$, $\sigma$, respectively, and we make the conventions $\frac{0}{0} = 1$, $\frac{1}{0} = +\infty$, $\ln 0 = -\infty$, $\ln{+\infty} = +\infty$.
\end{definition}

\section{Data Processing and Analysis}
\label{sec:data_processing_and_analysis}

This section details the data processing and analysis methodology that was used in order to prepare the classical Statlog (German Credit Data) dataset \cite{hofmann1994german} \cite{germancredit2026} for use in the quantum setting. Firstly we outline the dataset characteristics, variable selection procedures and lastly quantum encoding procedures for the selected data. 

\subsection{Dataset description}

The selected dataset for this investigation is the Statlog (German Credit Data) dataset created by Professor Hans Hofmann \cite{hofmann1994german}. This multivariate dataset aims to classify people as a good or bad credit risk. The orginal dataset is composed of 1000 instances that span 21 variables (7 numerical, 13 categorical, and the target). 

In the original dataset created by Professor Hofmann, all non numerical variables use a attribute code to define their characteristics (e.g The status of a person whose checking account is less than 0 Deutsche Marks (DM) is A11) for that reason it was decided that the investigation was going to use a curated version of the dataset \cite{germancredit2026} which transforms all the labels to their definition as a means of simplifying the readers' understanding of the dataset by eliminating that intermediate layer of label and category. Every mention to the dataset henceforth will refer to this curated version and not the original compiled by Professor Hofmann

A simple data analysis concluded that the dataset didn't have any problem in terms of completeness (as all rows include all 21 variables) nor uniqueness (as there is no instance of an exact duplicate). For these reasons no special cleaning procedure was done prior to variable selection.

\subsection{Variable selection with PhiK}

In order to hold quantum data for a dataset that contains 1000 instances of 20 variables each, the simulation would, at a maximum, store 1000 $2^n \times 2^n$ density matrices, with $n$ being the number of qubits used. This means that using the full 20 variables, one per qubit, would imply $2^{20} \times 2^{20} \approx 1.1 \times 10^{12}$ complex entries, and at 16 bytes each, that is about 16 TiB per matrix. It was decided that a correlation study over the target variable would be an adequate way to reduce this load. The reasons for this decision are: First, the investigation did not aim to produce a classifier and thus could use a smaller number of variables in the experiments. Second, the variables selected from a correlation study would be the most likely candidates to be chosen as significant by a classifier.

As mentioned previously however, most of the variables in this dataset are not numeric and thus a popular correlation analysis such as the Pearson correlation is not an adequate choice to evaluate variable correlation. For starters, for a nominal variable the Pearson's coefficient relies on an arbitrary choice for the label and since the proportions of the target variable in the dataset for each category are not the same across the board, a change in category label implies a change in the coefficient. Moreover the Pearson coefficient identifies well the linear relationships of variables but lacks for nonlinear cases.

For these reasons it was decided to use the PhiK method \cite{BAAK2020107043PHIK} to select the variables which show a consistent stronger correlation with the target variable. PhiK is a stronger candidate as it works well for both numerical and categorical variables correlations and it is able to identify nonlinear relationships between them.

We used Baak et al. PhiK library to measure the correlation and significance between each variable and the target and recorded the results in Table~\ref{tab:phik}. It is important to note that the library returns, for a pair of variables, two results: the first is $\phi_{K}$ which is the measurement of how strong the relationship between the two variables is. This result is calculated by calibrating a $\chi^2$ test statistic to a contingency table (populated with the categorical variables or a bin distributed numerical variables) with respect to a bivariate normal distribution. This calibration returns a $\phi_{K}$ with range of 0 (no association) to 1 (complete association). Since $\phi_{K}$ depends on the counting of the contingency table renumbering the categories no longer affects the end result. The second result is $Z$ which is a conversion of the p-value from the independence test into a number of standard deviations. A higher $Z$ provides more evidence that the variable is not independent from the target.

For the variable selection we chose to use $Z$ as although the $\phi_{K}$ measures the correlation between variables, the significance $Z$ of that correlation explains if that correlation is significant enough to be told apart from chance. The Bonferroni method states that, to ensure that the probability of at least one false positive across $k$ tests (in our case $k = 20$ for $20$ variables against the target) is at most $\alpha = 0.05$, each individual test must use a significance level of $\alpha' = \alpha/k = 0.05/20 = 0.0025$ \cite{bland1995multiple}. Here a false positive is a variable that is independent of the target but is selected anyway. Since $\alpha' = 0.0025$ corresponds to $Z \approx 2.81$, we used $Z > 2.81$ as the cutoff for the selection of the variables.

\subsection{Encoding of classical variables into quantum}
\label{subsec:encoding_variables}

Having chosen a reduced set of variables from the dataset (10 from the original 20), the next step was to encode the classical information from each variable into qubits which could be used in the quantum simulation. For this it is important to note that the variables were divided into two groups each with their own encoding:

\subsubsection{Categorical Variables}

These are categorical variables whose categories do not follow a natural ranking. An example for this is the variable $\texttt{purpose}$ which has ten categories (car(new), vacation, education, among others). As the reader can observe these categories don't follow a natural order as there is no way to tell if say car goes after or before education. Due to this it was decided to separate them from the categorical (ordinal) variablese that will be mentioned later on

The proposed encoding for these types of variables is given by Definition~\ref{def:encoding_categorical}

\begin{definition}
 \label{def:encoding_categorical} 
  (Method for encoding categorical variables)
  For a categorical variable with $K$ categories. When ecoding the label $c \in \{0, \dots, K - 1\}$ the resulting encoded qubit state $\ket{\psi}$ is given by the equation

  $$\ket{\psi} = RZ(\phi)H\ket{0} \text{with, } \phi = \frac{2\pi c}{K}$$

\end{definition}


This encoding ends up with a qubit state in one of $K$ equally distributed points across the equator of the Bloch sphere. We choose to place the qubit on the equator as because from Definition~\ref{def:trace_distance_vector} we can express $\tau$ in terms of the angle between to points of a circle $\Delta$ and the radius of that circle as $r\sin{\frac{\Delta}{2}}$. With this expression the reader can note that the minimum distance $\tau$ is maximized for all other angles on the sphere when the radius is maximum which happens in the equator of the sphere. More over one could argue that having a smaller $\theta$ (i.e the angle of rotation with regards to the y-axis of the Bloch sphere) would reduce $\epsilon$, and one would be right if not for the fact that it comes with the tradeoff of making the categories less distinguishable. In the case where $\theta = 0$ any rotation over the z-axis would invalidate since no rotation over the y-axis would make it a global phase.

This method assures then that $\tau$ between two categories is at least $\sin(\frac{\pi}{K})$. What this means in theory is that the privacy in the local setting won't change the final $\epsilon$ as regardless of the labels given to any category, the angle between the labels themselves might change but the possible angles between different categories will remain the same. However, what this encoding doesn't prevent is the fact that different categories can have different proportions. The labels given to each category can impact the distance $\tau$ between the dataset and that same dataset without a person included, which, as will be explained in Section~\ref{sec:finding_epsilon} is crucial when computing $\epsilon_{exp}$ and $\epsilon_{theo}$ and then in theory can lead to different results. In Appendix~\ref{ap:label_categorical} we compiled the $c$ value given to the variable's categories.

\subsubsection{Numerical and ordinal variables}

These are variables which do follow a specific order and that order should be taken into account in order to preserve characteristics that might be inherent to them. An example of these variables is $\texttt{month\_duration}$ which explains the loan's duration in months. A loan that goes for 4 months is clearly smaller than that of a loan that goes for 72, thus it is important to preserve that order.

The selected method to encode these variables is Dense Angle Encoding \cite{ibm_encoding}

\begin{definition}
  
  Method for encoding numerical and ordinal variables: For a pair of angles $\theta$ and $\phi$ the resulting dense angle encoding is
  
  $$\ket{\psi} = RZ(\phi)RY(\theta)\ket{0}$$

\end{definition}

The angles $\theta$ and $\phi$ are the normalization of the values of each variable from $0$ to $\pi$.

As the reader can observe thanks to dense angle encoding we can actually reduce the number of qubits neccesary for encoding the full 10 variables to 8 which helps reduce the computational toll the resulting qubits take overall. 

The question that remained however was, which variables were going to be encoded togheter? To answer this question we first created all 15 possible arrangements of the 5 numerical and ordinal variables into two pairs and a single variable. Then, we once again used the PhiK method to analyze the correlation between each pair of variables which is documented in Annex~\ref{tab:phik_numerical_ordinal}. From this small investigation it was concluded that the combination of variables that yielded the smallest correlation in the worst case was \texttt{status\_account} as the lone variable \texttt{status\_savings} and \texttt{month\_duration} as the first pair and \texttt{years\_employment} and \texttt{credit\_amount} as the second pair.

With the pairing concluded the next thing to tackle was the issue with the global phase that could be induced in this encoding. The problem lies in the fact that if we normalize the variable from $0$ to $\pi$ then there is a change that the initial RY leaves the value at either pole of the sphere, which in turn would make the RZ gate useless loosing the information of the second variable. The solution was to make the variables which use the RY gate and then a RZ gate be divided into bins of equal sizing. That way we assured that no matter the value of the first variable in either pair the second variable won't be lost to a global phase.
