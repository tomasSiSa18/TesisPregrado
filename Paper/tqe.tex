\section{Data Processing and Analysis}
\label{sec:data_processing_and_analysis}

This section details the data processing and analysis methodology that was used in order to prepare the classical Statlog (German Credit Data) dataset \cite{hofmann1994german} \cite{germancredit2026} for use in the quantum setting. Firstly we outline the dataset characteristics, variable selection procedures and lastly quantum encoding procedures for the selected data. 

\subsection{Dataset description}

The selected dataset for this investigation is the Statlog (German Credit Data) dataset created by Professor Hans Hofmann \cite{hofmann1994german}. This multivariate dataset aims to classify people as a good or bad credit risk. The orginal dataset is composed of 1000 instances that span 21 variables (7 numerical, 13 categorical, and the target). 

In the original dataset created by Professor Hofmann, all non numerical variables use labels to define their characteristics (e.g The status of a person whose checking account is less than 0 Deutsche Marks (DM) is A11) for that reason it was decided to use a curated version of the dataset \cite{germancredit2026} which transforms all the labels to their definition as a means of simplifying the readers understanding of the dataset by eliminating that intermediate layer of label and category.

Neither the original dataset nor the curated version have any problem in terms of completeness as all rows include all 21 variables nor uniqueness as there is no instance of an exact duplicate. For these reasons no special cleaning procedure was done.

\subsection{Variable selection with PhiK}

As the primary objective of this investigation was not to make a clasiffier but rather explore the capabilities that quantum computing could offer in terms protecting the input data, coupled with the fact that the simulation would at a maximum store 1000 $2^n \times 2^n$ density matrices (with $n$ being the number of variables) and thus a larger $n$ would likely need higher computational capabilities it was decided to select a subset of variables that in a true classifier setting would likely have the most incidence on training. 

As mentioned previously however, most of the variables in this dataset are not numeric and thus a popular correlation such as the Pearson correlation analysis would be fruitless. For this reason it was decided to use a PhiK correlation coeficient \cite{BAAK2020107043PHIK} which is a stronger candidate to measure the association between a pair of variables that are not necessarily numerical.

The PhiK correlation test gives for a pair of variables their $\phi_{K}$ which is how strong the association is and a significance $Z$ which states how statitically relevant that association really is.
